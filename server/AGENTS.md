# Agent 요약: Server

## 1. 책임 (Responsibility)
이 에이전트는 브라우저 확장 프로그램으로부터 사용자 행동 로그를 수집하여 MongoDB 데이터베이스에 저장하고, 요청 시 분석된 내비게이션 가이드를 제공하는 백엔드 API 서버입니다. "Follow Me!" 시스템의 중앙 데이터 허브 역할을 합니다.

## 2. 입력 / 출력 (Inputs / Outputs)
### 입력
- **HTTP POST `/api/v1/log_batch`**: 사용자 상호작용 이벤트의 JSON 배열을 수신합니다.
- **HTTP GET `/api/v1/guide?url=<URL>`**: 가이드가 요청된 URL을 수신합니다.
- **환경 변수**: 데이터베이스 연결을 위한 `MONGO_URI`, 실행 모드를 위한 `FLASK_DEBUG`, 서버 포트를 위한 `PORT`.

### 출력
- **데이터베이스 (`followme_db`)**:
  - **쓰기**: `event_logs` 컬렉션에 사용자 로그 배치를 기록합니다.
  - **읽기**: `analyzed_guides` 컬렉션에서 가이드 데이터를 읽습니다.
- **HTTP 응답**:
  - `201 Created`: 로그 배치가 성공적으로 수집되었을 때.
  - `200 OK`: 가이드를 찾았거나 찾지 못했을 때.
  - `400 Bad Request`: 잘못된 형식의 요청일 때.
  - `500 Internal Server Error`: 데이터베이스 또는 기타 서버 측 오류 발생 시.

## 3. 내부 구조 (Internal Structure)
- **`app.py`**: 메인 Flask 애플리케이션 진입점입니다. API 엔드포인트를 정의하고, 요청 파싱을 처리하며, 데이터베이스 모듈 호출을 조율합니다.
- **`db.py`**: MongoDB 연결을 관리하고 데이터베이스 작업을 추상화하는 헬퍼 함수(`insert_logs`, `get_guide_for_url`)를 제공하는 데이터베이스 인터페이스 모듈입니다.
- **실행 흐름**:
  1. Flask 앱이 시작되고 MongoDB에 연결합니다.
  2. `/log_batch` 요청을 받으면 타임스탬프를 추가하고 `db.insert_logs`를 호출합니다.
  3. `/guide` 요청을 받으면 `db.get_guide_for_url`을 호출하고 결과를 반환합니다.

## 4. 의존성 (Dependencies)
### 내부 모듈
- `db.py`: 모든 데이터베이스 상호작용에 사용됩니다.

### 외부 모듈
- `Flask`: 핵심 웹 프레임워크.
- `Flask-CORS`: 확장 프로그램의 교차 출처 요청을 처리합니다.
- `pymongo`: MongoDB 통신에 사용됩니다.
- `python-dotenv`: 환경 변수 관리에 사용됩니다.

## 5. 검사 결과 (Inspection Findings)
- **기능적 결함**: 코드 상 명백한 기능적 결함은 없습니다.
- **설계 결함**:
  - 데이터베이스 연결이 모듈 로드 시점에 설정됩니다. 시작 시 연결 실패하면 서버는 부분적으로 기능하지만 모든 DB 관련 요청은 실패합니다.
  - 수신되는 로그 데이터의 구조나 내용에 대한 유효성 검사가 없습니다.
- **유지보수 리스크**: `db.py` 모듈이 전역 `db` 객체를 사용하여 애플리케이션이 커질 경우 테스트와 향후 확장이 어려워질 수 있습니다.
- **프로토타입 흔적**: 오류 처리가 기본적(`db.py`의 `print()` 문 등)이며, 이는 프로토타입에는 일반적이지만 프로덕션 환경에는 적합하지 않습니다.
- **추천 리팩터링**:
  - 앱과 DB의 생명주기를 더 견고하게 관리하기 위해 Flask의 애플리케이션 팩토리 패턴을 구현합니다.
  - 수신되는 로그 배치에 대한 JSON 스키마 유효성 검사를 도입합니다.
  - 데이터베이스 연결 관리에 Flask의 애플리케이션 컨텍스트를 사용합니다.

## 6. 테스트 용이성 (Testability)
- **단위 테스트**: `db.py` 모듈은 `MongoClient`를 모의(mocking)하여 단위 테스트할 수 있습니다.
- **통합 테스트**: `app.py`의 Flask 엔드포인트는 테스트 클라이언트(`pytest-flask` 등)를 사용하여 HTTP 요청을 시뮬레이션하고 응답과 데이터베이스 상태 변경을 검증하여 테스트할 수 있습니다.
